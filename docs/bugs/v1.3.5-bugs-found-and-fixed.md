# v1.3.5 中发现的 Bug（已在重构中修复）

## Bug-1: handleSingleLine 中 function 命令 fall-through
- **严重等级**: 高
- **描述**: `switch` 语句中 `case 'function':` 缺少 `break`，导致每个 `function` 命令也走 `case "summon":` 的解析逻辑
- **定位**: `src/core/DataLoader.ts:702-706`
- **修复**: 添加 `break;`
- **已修复**: ✅

## Bug-2: addTag 无条件覆盖计数
- **严重等级**: 中
- **描述**: `if (value)` 设置 `value + 1` 后被 `this.tagsData.set(tagName, 1)` 无条件覆盖
- **定位**: `src/core/DataLoader.ts:219-222`
- **修复**: 将 `this.tagsData.set(tagName, 1)` 移入 `else` 分支
- **已修复**: ✅

## Bug-3: loadFunctionData useConcurrentControl=false 时跳过加载
- **严重等级**: 高
- **描述**: 仅 `if (useConcurrentControl)` 分支内有加载逻辑，`false` 时函数文件完全不加载
- **定位**: `src/core/DataLoader.ts:556-569`
- **修复**: 添加 `else` 分支用 `Promise.all` 全量并发加载
- **已修复**: ✅

## Bug-4: teams option 拼写错误
- **严重等级**: 低
- **描述**: `extractScoreboardData` 中 `case "opetion"` 应为 `case "option"`
- **定位**: `src/core/DataLoader.ts:735`
- **修复**: 修正拼写
- **已修复**: ✅
